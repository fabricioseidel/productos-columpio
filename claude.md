# Guía de Configuración: Creador de Productos — Columpio Kids

Esta guía contiene todas las instrucciones y scripts necesarios para poner en marcha y conectar el proyecto **Columpio Kids** con tus servicios de base de datos (**Supabase**) y almacenamiento de imágenes (**Cloudinary**).

---

## 💾 1. Configuración de Base de Datos (Supabase)

Para que la aplicación pueda listar, guardar y editar productos, debes crear las tablas correspondientes en tu base de datos de Supabase.

### Pasos
1. Ve a tu panel de control en [Supabase](https://supabase.com).
2. Entra en la sección **SQL Editor** (icono `>_` en el menú de la izquierda).
3. Haz clic en **New query** (Nueva consulta).
4. Pega el siguiente bloque de código y haz clic en **Run** (Ejecutar):

```sql
-- 1. Crear tabla de productos
CREATE TABLE products (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  barcode text NOT NULL UNIQUE,
  name text NOT NULL,
  category text,
  description text,
  sale_price numeric DEFAULT 0,
  offer_price numeric,
  measurement_unit text DEFAULT 'un',
  measurement_value numeric DEFAULT 1,
  is_active boolean DEFAULT true,
  image_url text,
  features jsonb, -- Guarda variante y subcategoría en formato JSON: { "variante": "...", "subcategoria": "..." }
  updated_at timestamp with time zone DEFAULT timezone('utc'::text, now()),
  created_at timestamp with time zone DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 2. Habilitar seguridad de acceso (RLS)
ALTER TABLE products ENABLE ROW LEVEL SECURITY;

-- 3. Crear políticas para permitir acceso público sin autenticación (ajustar según sea necesario)
CREATE POLICY "Permitir lectura publica" ON products FOR SELECT USING (true);
CREATE POLICY "Permitir insercion publica" ON products FOR INSERT WITH CHECK (true);
CREATE POLICY "Permitir actualizacion publica" ON products FOR UPDATE USING (true);
CREATE POLICY "Permitir eliminacion publica" ON products FOR DELETE USING (true);

-- 4. Crear tabla opcional de categorías (La app cargará fallbacks infantiles si esta tabla está vacía)
CREATE TABLE categories (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name text NOT NULL UNIQUE,
  is_active boolean DEFAULT true,
  created_at timestamp with time zone DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Habilitar RLS en categorías
ALTER TABLE categories ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Permitir lectura publica de categorias" ON categories FOR SELECT USING (true);
```

## 📷 2. Almacenamiento de Imágenes (Cloudinary)

Para que las imágenes subidas desde el creador de productos se guarden directamente en tu cuenta de Cloudinary, debes crear un **Preset de Carga sin Firma (Unsigned Upload Preset)**.

### Pasos
1. Inicia sesión en [Cloudinary](https://cloudinary.com).
2. Haz clic en el icono de engranaje **Settings** (Ajustes) abajo a la izquierda.
3. En el menú superior o lateral de ajustes, ve a la pestaña **Upload**.
4. Desplázate hacia abajo hasta la sección **Upload presets** y haz clic en **Add upload preset**.
5. Configura los siguientes parámetros en la pestaña **General**:
   - **Upload preset name:** Puedes dejar el nombre generado aleatoriamente o escribir uno personalizado (ej: `columpio_kids_preset`).
   - **Signing Mode:** Cámbialo obligatoriamente a **Unsigned** (Sin firma).
   - **Folder:** Opcionalmente escribe un nombre de carpeta donde se guardarán las fotos (ej: `productos`).
6. Haz clic en el botón verde **Save** arriba a la derecha.

## ⚙️ 3. Configuración en la Aplicación Web

Una vez que tengas tus llaves listas, agrégalas en la aplicación:

1. Abre el archivo `index.html` en tu navegador.
2. En la barra de navegación superior, haz clic en **Ajustes ⚙️**.
3. Introduce los siguientes datos:
   - **Supabase URL:** Lo encuentras en Supabase bajo *Project Settings ➡️ API ➡️ Project URL*.
   - **Supabase Anon Key:** Lo encuentras en Supabase bajo *Project Settings ➡️ API ➡️ Project API keys (anon public)*.
   - **Cloud Name:** Es el identificador de tu cuenta de Cloudinary (visible en tu Dashboard principal).
   - **Upload Preset:** El nombre del preset *Unsigned* creado en el paso anterior.
4. Haz clic en **Guardar Configuración**. Los datos quedarán grabados localmente en tu navegador de forma persistente.
